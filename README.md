# LogiData — Sistema de Gestão Logística

## Sobre

O **LogiData** é um projeto de banco de dados relacional desenvolvido como parte dos meus estudos em **Engenharia de Dados**.

O projeto simula uma operação de gestão logística, envolvendo clientes, produtos, pedidos, itens de pedidos, transportadoras e entregas.

A proposta é aplicar na prática conceitos de **SQL, SQLite, modelagem de dados, bancos de dados relacionais e análise de dados** a partir de um cenário de negócio.

---

## Projeto

O desenvolvimento do projeto está organizado em diferentes etapas, começando pela definição do cenário e das regras de negócio e avançando para a modelagem, construção do banco de dados, inserção dos dados, consultas SQL e análises.

O projeto completo está disponível no repositório:

**LogiData — Sistema de Gestão Logística**

---

## Principais etapas

- Definição do cenário de negócio;
- Definição das regras de negócio;
- Modelagem do banco de dados;
- Criação das tabelas;
- Inserção dos dados;
- Desenvolvimento de consultas SQL;
- Análise dos dados;
- Documentação do projeto.

---

## Tecnologias

- SQL
- SQLite

---

## Objetivo de aprendizado

Este projeto tem como objetivo consolidar meus conhecimentos em bancos de dados e SQL por meio da construção de uma solução baseada em um cenário próximo de uma aplicação real.

Durante o desenvolvimento, busco praticar não apenas a escrita de consultas, mas também a organização, documentação e estruturação de um projeto de dados.
